This sample shows how WebP images and a reusable icon look in a post. It uses generic copy and local artwork, not a personal story.

## Add a WebP image

![An abstract sun above overlapping sage hills.](/images/blog/demo-landscape.webp){: width="1200" height="640" decoding="async"}

*Caption: a local illustration in the site's colors.*

The Markdown image syntax includes alt text. The caption adds context below the image.

## Add an inline icon

The bookmark icon {% include icons/bookmark.svg %} is decorative. The text carries the note's meaning.
